The only changed variable

The instruction below was assembled by the pipeline, not a person: the failing git merge trace was routed against all 74 spec signatures (one Haiku call, ~$0.01), matched §13 Partial Failure & Atomicity, and that challenge file's workaround was injected verbatim into the rerun.

§13 — Partial Failure & Atomicity injected text, excerpt
Signature: exit 1 from a multi-step command whose output shows some
steps succeeded before a failure line

Tier: C (stateful logic; weak models apply the fallback below)

Parse partial-failure output to determine safe retry scope: identify
what completed, resume from the failed step rather than re-running
the whole operation, and verify state before any retry.

Limitation: if the tool emits only a text error with no structured
step information, verify current state before retrying — re-running
completed steps may cause duplicate side effects
